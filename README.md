# Простой файловый менеджер

Простое PHP-приложение для управления файлами, которое позволяет просматривать содержимое директорий и открывать изображения.



## Использование

Чтобы запустить приложение локально, используйте встроенный веб-сервер PHP из корневой папки проекта:

```bash
php -S localhost:8000 -t public/
```

После этого откройте браузер и перейдите по адресу `http://localhost:8000/`.

## Тестирование

Для запуска юнит-тестов выполните команду:

```bash
composer test
```

## Статический анализ

Чтобы провести статический анализ кода с помощью PHPStan, используйте команду:

```bash
composer stan
```

## Проверка стиля кода

Для проверки стиля кода без автоматического исправления (сухой запуск) выполните:

```bash
composer cs-check
```

Для автоматического исправления ошибок стиля кода используйте:

```bash
composer cs-fix
```
